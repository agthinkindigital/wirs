# Domínio (índice para agentes)

- Glossário canônico: `CONTEXT.md` (raiz).
- Especificação viva: `WIRS_MASTER_SPEC_PT-BR.md` (raiz).
- Decisões arquiteturais: `docs/adr/`.
- Docs de providers externos: `docs/providers/<provider>.md`.
- Tracker: GitHub Issues (`docs/agents/issue-tracker.md`).
- Triage: `docs/agents/triage-labels.md`.

Vocabulário do domínio deve aparecer em nomes de módulos, classes e regras.
Termo do `CONTEXT.md` sem correspondência no código é linguagem morta: sinalize.
Novo conceito de negócio no código exige atualização do `CONTEXT.md`.
