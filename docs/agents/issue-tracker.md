# Issue tracker

Fonte persistente de escopo, dependências, aceite e status: **GitHub Issues**
do repositório `agthinkindigital/wirs`.

- Uma Issue por slice vertical (comportamento completo, pequeno, verificável).
- Toda Issue tem: objetivo, critérios de aceite verificáveis, `Blocked by` com
  IDs reais, e evidência de verificação (comandos/testes).
- `ORCHESTRATOR-ROADMAP.md` resume Epics; a Issue da Epic é a fonte detalhada.
- `ESTADO_ORQUESTRATOR.md` é só a visão operacional da DAG — nunca a fonte.
- Nunca feche Issue pai sem autorização explícita.
