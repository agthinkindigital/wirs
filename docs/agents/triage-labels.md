# Triage labels

Vocabulário de triage (defaults):

- `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`

Tipos:

- `type:feature`, `type:security`, `type:test`, `type:docs`, `type:refactor`,
  `type:provider`, `type:adapter`

Áreas:

- `area:core`, `area:wordpress`, `area:reporting`, `area:rules`,
  `area:database`, `area:remote`

Prioridades (Seção 17 do spec):

- `priority:P0` — primeiro vertical slice útil
- `priority:P1` — MVP confiável
- `priority:P2` — maturação pós-MVP
- `priority:P3` — expansão de plataforma/produto
